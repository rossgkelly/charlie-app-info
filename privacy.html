Privacy information

Google data accessed and used

When authorized, Charlie can read Google Calendar information, including accessible calendars and event titles, dates, locations, attendees, and descriptions. Calendar permissions also support changes requested by authorized users. The current OAuth Calendar scope is broad enough to manage and delete accessible calendars; the assistant's operating instructions require explicit confirmation before deleting an event.

Calendar information is used to answer questions, prepare requested summaries, and carry out scheduling instructions. Necessary information may be processed by the configured AI provider and included in responses delivered through the configured messaging service. Google processes the API and authorization requests. The public informational website does not receive calendar data or OAuth tokens.

Storage and control

Charlie runs on the operator's own computer. OAuth refresh tokens are stored in an encrypted local keyring. Configuration, assistant memory, conversation history, and private recovery backups may retain information needed for the assistant's operation; they are not published with this website.

The owner can revoke access through the Google Account's third-party connections settings and remove local credentials, stored assistant information, and recovery copies. Revoking access prevents future authorized API access but does not automatically delete previously stored information.

Limited use

Google user data is used to provide the personal-assistant features described here. It is not sold or used for advertising. Charlie's use and transfer of information received from Google APIs must adhere to the Google API Services User Data Policy, including its Limited Use requirements.
